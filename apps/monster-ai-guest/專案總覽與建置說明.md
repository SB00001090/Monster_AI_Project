**應用名稱：** Monster AI 訪客試玩版

**版本：** `1.0.0-guest`（versionCode `10000`）  
**開發者：** Suckbob  
**發行商：** Monster_Ai_hk  
**最低支援：** Android 8.0（API 26）  
**目標 SDK：** Android 14（API 34）

## 1. 這是什麼

完全本地、**無帳號 / 無付費 / 無雲端同步** 的訪客免費試玩 Android 客戶端。  
僅開放 3 名公開角色，每日試玩 **30 分鐘**，超時自動結束並引導下載正式版。

| 功能 | 訪客版 |
|------|--------|
| 雪兒（薩摩耶）/ 小桃（柴犬）/ 布丁（柯基） | ✅ 可對話 |
| 其他角色 / 自訂角色 | 🔒 鎖定 |
| 每日試玩 | 30 分鐘 |
| 聊天儲存 / 匯出 | ❌ |
| 付費 / 帳號 / 雲端 | ❌ |
| 浮水印 | 右下角常駐「訪客試玩版｜Monster_Ai_hk」 |
| 主畫面橫幅 | 「免費試玩中，完整版請下載正式版」 |

## 3. 一鍵建置指令

### 前置

1. 安裝 **Android Studio** 或 **Android SDK**（含 build-tools、platform 34）
2. 安裝 **JDK 17**
3. （建議）設定環境變數 `ANDROID_HOME` 指向 SDK

### Debug APK（最快驗證）

```bat
cd apps\monster-ai-guest
build-guest-apk.bat
```

或：

```bat
cd apps\monster-ai-guest
gradlew.bat assembleDebug
```

### Release APK（需簽名設定）

1. 依 `簽名與打包步驟說明.md` 建立 keystore 與 `keystore.properties`
2. 執行：

```bat
cd apps\monster-ai-guest
build-guest-apk.bat release
```

或：

```bat
gradlew.bat assembleRelease
```

## 4. APK 輸出路徑

| 類型 | Gradle 預設路徑 | 一鍵脚本副本 |
|------|-----------------|--------------|
| Debug | `app/build/outputs/apk/debug/app-debug.apk` | `dist/MonsterAi-Guest-1.0.0-guest-debug.apk`（倉庫根 `dist/`） |
| Release | `app/build/outputs/apk/release/app-release.apk` | `dist/MonsterAi-Guest-1.0.0-guest-release.apk` |

> 若 release 未配置簽名，可能產出 `app-release-unsigned.apk`，需自行 `apksigner` 簽名。

## 5. 訪客限制實作對照

| 需求 | 實作位置 |
|------|----------|
| 僅 3 角色 | `GuestCharacters.UNLOCKED` |
| 每日 30 分 | `GuestModeManager` + `BuildConfig.DAILY_TRIAL_SECONDS=1800` |
| 超時結束 | `ChatActivity.onTrialExpired` → `TrialEndedActivity` |
| 不存聊天 | `ChatActivity` 僅 `mutableList`，`onDestroy` 清空 |
| 不匯出 / 不自訂 | `isExportAllowed()` / `isCustomCharacterAllowed()` 固定 false |
| 浮水印 | 各 layout 右下 `tvWatermark` |
| 試玩橫幅 | `activity_main.xml` → `tvBanner` |
| 無付費帳號雲端 | Manifest 無 Billing；`isBillingEnabled` 等固定 false |

## 6. 手動測試清單（建議）

1. 安裝 Debug APK，啟動見橫幅與倒數 `30:00`
2. 僅見雪兒 / 小桃 / 布丁 三張卡可點「開始對話」
3. 送出訊息有角色回覆，親密度 +1
4. 返回主畫面再進對話，**訊息已消失**（不存檔）
5. 右下角浮水印常駐
6. 倒數歸零（可暫時把 `DAILY_TRIAL_SECONDS` 改成 `30` 驗證）→ 自動進結束頁
7. 「下載正式版」可開啟瀏覽器
8. 無登入 / 付費入口

## 7. 潛在 bug 與邊界（建置前注意）

1. **日期跨日**：試玩秒數依 `yyyy-MM-dd` 重置；午夜跨日時若 App 開著需重進畫面才刷新 day key  
2. **僅對話前景計時**：主畫面停留不扣時間；若需「開 App 即扣時」要改 `MainActivity`  
3. **多進程 / 清資料**：清除 App 資料會重置當日已用時間（訪客可接受）  
4. **快速連點送出**：已 `btnSend.isEnabled` 短暫禁用，極端連點仍可能雙送  
5. **旋轉螢幕**：Manifest 鎖定 portrait；若解除鎖定，聊天 memory 會因重建清空  
6. **正式版 URL**：`BuildConfig.OFFICIAL_DOWNLOAD_URL` 請改成真實商店或官網  
7. **離線回覆**：`SimpleReplyEngine` 非 LLM，僅關鍵字；正式版需接 FastAPI  
8. **儲存權限**：已宣告舊版 READ/WRITE，執行時**不請求**（因不寫聊天）
