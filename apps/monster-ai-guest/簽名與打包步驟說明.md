# 簽名與打包步驟說明

**應用：** Monster AI 訪客試玩版  
**包名：** `com.monster_ai_hk.guest`  
**版本：** `1.0.0-guest`  
**開發者：** Suckbob  
**發行商：** Monster_Ai_hk

> 警告：請勿把真實 `keystore.properties`、`.jks` 密碼提交到 Git。

---

## 1. 產生 Keystore（首次）

在 `apps/monster-ai-guest` 目錄執行（需 JDK `keytool`）：

```bat
mkdir keystore 2>nul
keytool -genkeypair -v ^
  -keystore keystore\monster-ai-guest.jks ^
  -alias monster_ai_guest ^
  -keyalg RSA -keysize 2048 -validity 10000 ^
  -dname "CN=Monster AI Guest, OU=Monster_Ai_hk, O=Monster_Ai_hk, L=HK, ST=HK, C=HK"
```

依提示輸入 **store 密碼** 與 **key 密碼**（可相同）。  

建議填寫：

| 欄位 | 建議值 |
|------|--------|
| CN | Monster AI Guest / Suckbob |
| OU / O | Monster_Ai_hk |
| 別名 alias | `monster_ai_guest` |

---

## 2. 建立 keystore.properties

複製範本：

```bat
copy keystore.properties.example keystore.properties
```

編輯 `keystore.properties`：

```properties
storeFile=keystore/monster-ai-guest.jks
storePassword=你的密碼
keyAlias=monster_ai_guest
keyPassword=你的密碼
```

`app/build.gradle` 的 `signingConfigs.release` 會自動讀取此檔。

---

## 3. 打包 Release APK

```bat
cd apps\monster-ai-guest
build-guest-apk.bat release
```

或：

```bat
gradlew.bat clean assembleRelease
```

### 輸出

- 已簽名：`app/build/outputs/apk/release/app-release.apk`
- 副本（脚本）：`dist/MonsterAi-Guest-1.0.0-guest-release.apk`

### 驗證簽名（可選）

```bat
apksigner verify --verbose app\build\outputs\apk\release\app-release.apk
```

（`apksigner` 位於 Android SDK `build-tools\<version>\`）

---

## 4. 僅 Debug（開發測試）

不需 keystore，使用 Android 預設 debug 簽名：

```bat
build-guest-apk.bat
```

輸出：`app/build/outputs/apk/debug/app-debug.apk`  
（debug 的 applicationId 會加後綴 `.debug` → `com.monster_ai_hk.guest.debug`）

---

## 5. 安裝到裝置

```bat
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

或：

```bat
adb install -r dist\MonsterAi-Guest-1.0.0-guest-debug.apk
```

---

## 6. 與正式版區隔

| 項目 | 訪客試玩版 | 正式版（參考） |
|------|------------|----------------|
| applicationId | `com.monster_ai_hk.guest` | 另行定義（勿衝突） |
| 簽名 keystore | `monster-ai-guest.jks` | 建議**不同** keystore |
| 付費 / 帳號 | 關閉 | 依正式產品 |

同一支手機可同時安裝訪客版與正式版（包名不同）。

---

## 7. 備份建議

- 將 `.jks` 離線加密備份  
- 密碼使用密碼管理器  
- 遺失 keystore 將無法以同一簽名更新上架
