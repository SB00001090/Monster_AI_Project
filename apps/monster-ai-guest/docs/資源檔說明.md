## 字串 `res/values/strings.xml`

| 資源名 | 用途 |
|--------|------|
| `app_name` | 啟動器名稱「Monster AI 訪客試玩版」 |
| `guest_banner` | 主畫面試玩橫幅 |
| `timer_remaining` | 倒數顯示 |
| `select_character` | 角色區標題 |
| `intimacy_label` | 親密度 |
| `input_hint` | 輸入框提示（含不存檔說明） |
| `trial_ended_*` | 試玩結束文案 |
| `meta_line` | 開發者 / 發行商 / 版本 |

修改對外文案時優先改此檔，避免硬編碼。

---

## 顏色 `res/values/colors.xml`

Neon 深色主題：

- `bg_dark` / `bg_card` — 背景  
- `neon_cyan` / `neon_pink` — 強調色與倒數  
- `danger` / `warning` — 時間將盡  
- `watermark` — 半透明浮水印  

---

## 主題 `res/values/themes.xml`

`Theme.MonsterAiGuest`：Material NoActionBar，狀態列深色。  
按鈕樣式：`Widget.Monster.Button` / `.Secondary`。
