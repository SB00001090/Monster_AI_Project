# 日常操作（方便整理 · 維持運作）

**Developed by Suckbob | Guardian Ai**

## 原則

1. **Git 根 = 本倉庫根目錄**（不必另建 Monster_AI_Project 資料夾）  
2. **實際程式路徑不要硬改名**（`monster_ai/`、`guardian_ai/` 維持）  
3. **用入口腳本整理工作流**，概念名只出現在文件裡  

## 每天怎麼開

| 需求 | 做法 |
|------|------|
| 圖形選單（推薦） | 雙擊 **`start.bat`** |
| 只開生成 / Web | `python start_monster_ai.py` 或 `run.bat` |
| 只開 24/7 守護 | `python start_monster_guard.py` |
| 看守護狀態 | `python start_monster_guard.py status` |
| 整理總覽 | `python scripts/project_status.py` 或選單 [4] |

## 檔案放哪裡（整理規則）

| 要改什麼 | 放哪 |
|----------|------|
| 聊天 / 生成 / 平台 API | `monster_ai/` |
| E2E 同步、幼兒學習、OC | `monster_ai/modules/guardian/` |
| MonsterGuard 24/7 | `guardian_ai/monster_guard/` |
| HTTP 掃描 API | `monsterguard/` |
| Discord bot 管線 | `monster_ai/modules/discord/guard/` |
| 討論區 UI | `client/` + `server/` |
| 說明文件 | `docs/` + `deploy/guardian/` |
| 本機密鑰 / 執行資料 | **不要進 git**：`config.yaml`、`.env`、`data/` |

## 不要做的事

- 不要把整個 `monster_ai` 改名成 `monster_ai_file`（會全線 import 失敗）  
- 不要 commit `discord.token.local`、keystore、`.env`  
- 不要在 `data/` 當原始碼倉庫
